2. **Формула сердечно-сосудистого (сосудистого) возраста:**
   - Реализована аналитическая замкнутая формула:
     $$\text{heart\_age} = \exp\left(\frac{L_{\text{patient}} - C_{\text{ref}}}{\beta_{\text{age}}}\right)$$
     где $C_{\text{ref}}$ — не-возрастные члены эталонного оптимального профиля (САД 125 без лечения, ОХС 180 мг/дл, HDL 45 мг/дл, не курит, без диабета).
   - Для эталонного профиля любого возраста доказано и протестировано: $\text{heart\_age} \equiv \text{age}$ с точностью $< 0.05$ лет.
3. **Оценка ожидаемой продолжительности жизни:**
   - Линейная интерполяция по официальной таблице смертности ВОЗ для Узбекистана (`core/clinical.get_who_remaining_life`).
   - Расчет ожидаемой продолжительности жизни с поправкой на сердечно-сосудистый возраст: $\text{life\_estimate} = \text{age} + e_x(\text{heart\_age})$.
4. **Конвертация единиц (`core/units.py`):**

## Фаза 3 — Нейросеть, обучение и объяснимость (XAI)

**Статус:** Выполнено

### Что сделано:
1. **Переписана нейронная сеть (
eural_network.py):**
   - Чистая реализация на NumPy без зависимостей от PyTorch/TensorFlow.
   - Архитектура: MultiTask MLP 13 признаков -> Dense(32) -> Dense(16) -> 2 головы (chd: Sigmoid, diabetes: Sigmoid).
   - Активация: Swish ( \cdot \sigma(x)$) с точной аналитической производной.
   - Регуляризация: Inverted Dropout (=0.10$) + L2 весовая регуляризация (^{-4}$).
   - Оптимизатор: Adam с bias-correction и gradient clipping (.0$).
   - Вычисления в 
p.float64 для предотвращения потери точности.
   - Метод input_gradient(): точный аналитический градиент вероятности выхода по вектору входов (проверен против конечных разностей, относительная погрешность $< 10^{-4}$).
   - Метод predict_with_uncertainty(): байесовская аппроксимация неопределенности через Monte Carlo Dropout с детерминированным фиксированным сидом.
   - Метод integrated_gradients(): расчет вкладов признаков по аксиоме полноты Сундарараджана (Integrated Gradients) по прямолинейной траектории от здорового референсного профиля.
2. **Скрипт обучения (scripts/train_model.py):**
   - Обучение на data/processed_data.npz (Train=2968, Val=636, Test=636).
   - Early stopping по validation loss с восстановлением лучших весов.
   - Обучены базовые модели Logistic Regression для обеих задач.
   - Рассчитаны честные тестовые метрики:
     - **ИБС (CHD):**
       - NN ROC-AUC = 0.675 (95% bootstrap CI: [0.607, 0.735])
       - Logistic Regression ROC-AUC = 0.698 (95% CI: [0.638, 0.758])
       - D'Agostino general CVD reference = 0.700 (95% CI: [0.641, 0.760])
       - Brier Score: NN = 0.1210, LR = 0.1185
       - Порог 10%: Чувствительность = 75.26%, Специфичность = 53.62%
       - Порог 20%: Чувствительность = 40.21%, Специфичность = 82.56%
     - **Диабет (Diabetes скрининг):**
       - NN ROC-AUC = 0.884 (95% bootstrap CI: [0.738, 0.998])
       - Logistic Regression ROC-AUC = 0.827
     - Калибровочные кривые (10 бинов).
   - Сохранены артефакты:
     - models/model_weights.npz (веса без использования pickle, метаданные стандартизации).
     - models/metrics.json (все метрики без хардкода).
     - models/model_card.json (карточка модели по стандарту Mitchell et al.).
3. **Модуль инференса и симуляций (core/risk_model.py):**
   - load_risk_model() с @st.cache_resource декоратором.
   - predict_patient(): 10-летний риск ИБС с MC Dropout неопределенностью, вероятность диабета, сердечно-сосудистый возраст, ожидаемая продолжительность жизни по таблицам Узбекистана.
   - explain_prediction(): расчет вкладов факторов риска через Integrated Gradients (50 шагов) от эталонного здорового профиля того же возраста и пола. Доказана полнота ($\sum \text{attributions} \approx \Delta P$).
   - simulate_intervention(): виртуальная симуляция клинических вмешательств (отказ от курения, нормализация давления, статины) с расчетом $\Delta\text{CHD}$, $\Delta\text{heart\_age}$, $\Delta\text{life\_exp}$.
   - compute_risk_trajectory(): динамика рисков на горизонте 0–20 лет для текущего и оптимизированного сценариев.
4. **Тестирование (	ests/test_neural_network.py, 	ests/test_risk_model.py):**
   - 12 тестов написаны и пройдены (12 passed).

## Фаза 4 — Рекомендации, связанные с ИИ (core/recommendations.py)

**Статус:** Выполнено

### Что сделано:
1. **Клинические правила на основе доказательных рекомендаций:**
   - Курение: отказ от курения (WHO / ESC 2021 Prevention Guidelines).
   - Артериальное давление: контроль АД до целевого < 130/80 мм рт.ст. (ESC/ESH 2018 / WHO 2021).
   - Липидный профиль: снижение ОХС на 20% (NCEP ATP III / ESC 2019 Dyslipidemia Guidelines).
   - Масса тела: оптимизация ИМТ до нормального < 25 (WHO 2020 Healthy Weight Standards).
   - Гликемия: контроль уровня глюкозы и консультация эндокринолога (ADA Standards of Care 2024 / WHO).
2. **Прямая связь с нейросетью и клиническими формулами:**
   - Для каждой применимой интервенции запускается симуляция simulate_intervention(patient, changes).
   - Рассчитываются точные количественные эффекты: $\Delta\text{CHD}$ (в процентных пунктах), $\Delta\text{heart\_age}$ (в годах), $\Delta\text{life\_exp}$ (в годах).
3. **Динамическая персонализированная приоритизация:**
   - Вмешательства сортируются по величине выигрыша (абсолютное снижение 10-летнего риска ИБС), а не по захардкоженному списку.
   - Выделяются ТОП-3 шага с максимальной отдачей для конкретного человека.
   - Рассчитывается кумулятивный совокупный эффект при соблюдении всех рекомендаций.
4. **Удаление сомнительных эвристик:**
   - Полностью исключен старый блок псевдомедицинских домыслов «Возможные симптомы» (головная боль при АД > 140 и т.д.).
5. **Тестирование (	ests/test_recommendations.py):**
   - Тесты подтвердили: для эталонного здорового человека список интервенций пуст (предлагается поддержание здорового образа жизни), для профиля высокого риска шаги ранжируются по снижению риска, дельты корректны.
   - Все тесты пройдены (2 passed in 3.08s).
